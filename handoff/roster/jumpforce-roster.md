# Jump Force roster (57 playable)

Source: Wikipedia, *Jump Force* → Characters → Playable characters
(`en.wikipedia.org/wiki/Jump_Force`, retrieved 2026-10-26).

**40 launch + 3 added in a free update + 14 DLC = 57 playable characters across 16 series.**
The three free-update additions are not itemised separately in that source, so the table marks
DLC only; treat every non-DLC entry as "base roster".

`[DLC]` = Character Pass content. The commercial game was delisted on 2022-02-08, so DLC
availability is irrelevant here — this list is a *design target*, not a shopping list.

## Character-sourcing notes (for T5)

Community M.U.G.E.N characters exist for most of these series, but availability and quality
vary enormously, and the current best-known source for each is a research task, not an
assumption. When evaluating a candidate:

- Prefer `mugenversion = win` or `1.0`; 4:3-era sprite sizes (1–6 MB `.sff` is the safe band
  measured from the source pack's own roster).
- Reject 1280×720 `localcoord`, `trans = sub` effects, and multi-palette `RemapPal` costumes.
- Note whether the character is a JUS-style edit (cheap, portable) or a full HD build
  (expensive, crash-prone).
- Where no community character exists, substitute the closest equivalent from the same series
  (e.g. another Bleach captain) and record the substitution — never leave a silent gap.

## Same-series starting points already proven by the source pack's demo

These franchise folders existed in the demo build, so characters in these series are
already demonstrated to work on this asset pipeline: Dragon Ball (Janemba), Street Fighter
(Gouken), KOF (Goenitz), Melty Blood (Shiki Nanaya), Pokémon (Lucario), Rage of the Dragons
(Pupa), The Last Blade (Kaede), Cartoon (Bender).
